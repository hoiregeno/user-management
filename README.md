# User Management
A lightweight PHP CRUD application to create, read, update and delete user records, featuring basic CSS styling.

# Features
* **Create:** Add new user records to the system.
* **Read:** View existing user records.
* **Update:** Modify current user details.
* **Delete:** Remove user records.

# Tech Stack
* PHP (Backend logic and routing)
* CSS (Basic frontend styling)

# Project Structure
* `index.php` - Main dashboard displaying user records.
* `add.php` - Form interface for adding new users.
* `edit.php` - Form interface for modifying existing user details.
* `actions.php` - Handles the backend execution of CRUD operations.
* `style.css` - Contains the application's basic styling.
